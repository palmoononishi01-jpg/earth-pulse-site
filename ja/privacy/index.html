プライバシーポリシー

運営者: 【未設定】 · 最終改定日: 2026-11-23

【未設定】（以下「運営者」）は、無料の3D地球儀サービス「EARTH PULSE」（以下「本サイト」）における情報の取り扱いを、次のとおり定めます。

取得する情報と端末内の保存

本サイトには会員登録・ログイン・投稿フォームがなく、運営者のサーバーに個人情報を保存することはありません。

お使いのブラウザの中（localStorage）には、次の情報だけを保存します。これらは端末の中にとどまり、運営者のサーバーへは送信されません。Cookie ではありません。

  • 画質などの表示設定
  • 自然現象の「既読」にした時刻（新着の表示に使います）
  • 選んだ言語

サーバーのアクセスログ

本サイトを配信するサーバーは、アクセスの記録（IPアドレス、日時、閲覧したURL、ブラウザの種類、参照元など）を自動的に記録します。運営者は、障害の調査、不正なアクセスの防止、利用状況の集計のためにこの記録を利用することがあります。

広告

現在は広告を使用していません。広告を開始する場合は、事前にこのページを更新します。

アクセス解析

現在はアクセス解析のツール（タグ）を使用していません。サーバーのアクセスログの集計のみで、利用状況を把握することがあります。

外部への通信

地球儀が表示する統計・地図・自然現象のデータは、本サイトのサーバーから読み込みます。地球儀の画面が、データ提供元の API に直接アクセスすることはありません。

共有ボタンは、押したときにだけ、X などの投稿画面を新しいウィンドウで開きます。押すまでは外部へ通信しません。出典などの外部サイトへのリンクを開いた先では、そのサイトの方針が適用されます。

第三者への提供

運営者は、法令に基づく場合を除き、利用者の情報を第三者に提供しません。
